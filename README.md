## 📌 Overview
This project is a Virtual Reality (VR) chemistry lab simulation developed at Missouri State University in collaboration with the Computer Science department and a Chemistry faculty partner.

The goal was to create an **immersive and interactive learning environment** that allows users to simulate real laboratory procedures safely within a virtual space.

## 🎮 Features

- Immersive 3D laboratory environment  
- Real-time user interaction with lab equipment  
- Object manipulation within VR space  
- Scene navigation and user input handling  
- Simulation of chemistry lab procedures  

---

## ⚙️ System Design

The application focuses on real-time interaction and simulation:

- User inputs are captured and processed within the Unity engine  
- Objects respond dynamically to user actions in the VR environment  
- Scene logic controls interactions between lab elements and user inputs
